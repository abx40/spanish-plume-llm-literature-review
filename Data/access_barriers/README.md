# Post-search access analysis

These are analyses of what the five initial discovery runs missed, not results
returned by any one model. `omission_audit.csv` records the 41 benchmark papers
missed by all five systems and this project's access findings and explanations.
`journal_recall.csv` groups pooled model matches by journal; its denominators
come from the separately credited benchmark in `../discovery/benchmark/`.

The source reports and model-match results remain in `../discovery/`. The
authentication experiment, which directly compares runs before and after
institutional login, is in `../authentication/`.
