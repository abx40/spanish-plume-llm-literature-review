# Benchmark source and credit

`benchmark_reference.csv` is a limited, adapted reference table for the
102-article gold standard. It is **not** a model output or a result of this
project's discovery searches. The bibliographic fields, original database
numbers, search codes, and `how_cited` values come from the source dataset.
`SPxxx` identifiers and `benchmark_class` (essential/informative/passing) are
this project's crosswalk and simplified mapping of the source codes.

**Dataset:** Schultz, David; Lowe, Douglas; Herrerias Azcue, Francisco (2024).
*Spanish Plume Literature Review and Case Studies*. University of Manchester.
[DOI: 10.48420/28022981.v1](https://doi.org/10.48420/28022981.v1).
The source dataset is published under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

**Related review:** Schultz, David M.; Young, Martin V.; Kirshbaum, Daniel J.
(2025). *The Spanish Plume Elevated Mixed Layer: A Review of Its Use and Misuse
within the Scientific Literature*. Monthly Weather Review.
[DOI: 10.1175/MWR-D-24-0139.1](https://doi.org/10.1175/MWR-D-24-0139.1).

The original workbook and its full set of classifications are available from
the dataset DOI. This folder contains only the fields needed to identify and
stratify the papers for the discovery comparison. Model matches are in the
parent `discovery/` folder. The post-search audit is in `Data/access_barriers/`.
